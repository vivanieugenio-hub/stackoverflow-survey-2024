# 📊 Stack Overflow Developer Survey 2024 — Análisis Exploratorio

Análisis exploratorio del dataset de Stack Overflow 2024 con más de 65.000 respuestas de developers de todo el mundo.

## 🛠️ Herramientas
- Python (Pandas · Matplotlib)
- Google Colab

## 🔍 Preguntas analizadas
1. ¿Cuáles son los lenguajes de programación más usados?
2. ¿Qué porcentaje de developers usa herramientas de IA?
3. ¿Cuáles son los roles mejor pagos?
4. ¿Cuántos años de experiencia tienen los roles de datos?
5. ¿Qué países tienen los salarios más altos?

## 📁 Dataset
[Stack Overflow Developer Survey 2024](https://survey.stackoverflow.co/)
